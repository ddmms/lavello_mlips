## 2024-06-25 - Pandas DataFrame Iteration Bottleneck
**Learning:** In data handling files like `verify_processed_omol25.py`, iterating over large Pandas DataFrames using `df.iterrows()` is a massive anti-pattern. `df.iterrows()` yields a Pandas Series for each row, adding significant overhead (10x-20x slower).
**Action:** When iterating over a DataFrame is necessary, convert the DataFrame to a list of dicts first using `records = df.to_dict('records')` and then iterate. Remember to update any downstream method calls that assume the row is a Pandas Series (like `row.to_dict()`) since it will now be a standard Python dictionary.
